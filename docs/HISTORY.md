# 序 · DEQUE
原生 Android / Java 17 / SQLite，最低 Android 6。

## 功能
侧栏管理队列；独立队列设置与新队列默认设置；队头/队尾插入；从上到下优先级升高；上下按钮排序；完成及每队列独立回收站；恢复至原队列队尾；长按事项编辑。数据保存在应用私有 SQLite 数据库，退出后保留。

## 构建
使用 Android Studio 打开本目录，安装 Android SDK Platform 33，使用 JDK 17。或配置 ANDROID_HOME 后运行：

    .\gradlew.bat :app:assembleDebug

产物：app/build/outputs/apk/debug/app-debug.apk。
2026-11-13：使用 F:\SDK、JDK 17、Gradle 8.0.2 完成 assembleDebug 构建（31 项任务通过），已生成调试 APK。已补充固定版本 Gradle Wrapper。首次使用 Wrapper 需要下载对应 Gradle 分发包。模拟器启动受阻：缺少硬件加速驱动，尚未进行运行时及真机验收。可通过 USB 调试连接 Android 手机安装 APK；或在 Windows 启用 Windows Hypervisor Platform 并重启后再启动模拟器。

## 同步设计与后续工作
队列与事项使用 UUID；记录 updated 时间；完成状态与原 queueId 分开保存；队列删除保留 deleted 墓碑，方便未来同步。
当前版本仅离线使用，没有同步网络请求。正式同步前应把数据操作从 Activity 提取为 Repository，增加事务性 outbox、设备 ID、服务端版本及游标；服务器分配单调递增版本并幂等处理 operationId，避免依赖客户端时钟。任务排序应按队列作为一个原子操作提交；队列删除在服务端级联处理，冲突通过版本检测并明确提示用户。PC 客户端复用协议及 UUID，不直接共享 SQLite 文件。

## 验收
建立两个队列，在各自队头与队尾添加事项，确认颜色和顺序；上下移动后重启核对；完成后只在所属回收站出现；恢复后回到原队列；修改本队列默认设置不影响其他队列；修改新队列默认设置后创建队列验证；删除当前及最后一个队列；验证空标题被阻止。

## 1.5 备注与 DDL
旧数据库自动添加 notes、deadline 与各队列 reminderMinutes 字段，保留原数据。创建时可选备注，卡片以 ▤ 标记，点击卡片查看完整内容；日期及时间选择器支持年月日时分，DDL 可清除。队列设置可配置提前提醒分钟数，默认 60 分钟。提醒状态（包括逾期）在界面内每秒检查；返回前台也会检查。提醒事项浅红色置顶，按 DDL 升序；其余保持手动顺序，绿色渐变从首个普通事项重新开始。提醒事项的自动优先顺序不允许手动拖动覆盖。回收站不参与提醒，恢复时选择队头或队尾，恢复后已到提醒时限的事项仍优先置顶。
这是应用内视觉提醒，不包含后台系统通知。DDL 以时间戳存储，以设备本地时区显示。
验证：覆盖升级及启动成功；完整日期选择、时间流逝和多事项排序仍需交互验收。
