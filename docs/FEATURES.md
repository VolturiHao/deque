# 功能设计

## 队列与主页
侧栏切换队列，支持创建、改名、删除、长按拖动。队列排序按 position、rowid 升序；删除最后一个可见队列会创建默认队列。每个队列有独立设置和回收站，全局设置从侧栏底部进入。新建队列继承全局 tail 默认值。
主页有待办/回收站分段标签：点击或横滑切换；选中背景滑动，仅下方内容过渡，顶部标题不参与整页淡入淡出。横向位移超过 80dp 且大于纵向两倍才识别切页，拖动事项或编辑标题时不切页。

## 创建、编辑与备注
创建/编辑共用底部面板。标题必填，备注可选；DDL 可选、可清除。创建分别提供队头/队尾按钮；标题回车按本队列 tail 插入，编辑回车保存，不改变事项位置。备注可多行，卡片右侧独立图标提示，点击卡片/备注图标查看详情。回收站保持只读，无编辑菜单。
事项标题、顶部队列标题双击可原位编辑：回车、点击外部或失去焦点保存；空值保留旧标题；返回取消。编辑态描边与底色随文字宽度伸缩，最大为可用宽度，无顶部持续提示条。编辑期间暂停 DDL 刷新。事项单击查看详情与长按拖动需要与双击手势共同验收。

## 排序与 DDL
队头高优先级，position 越小越靠前。手动端点插入用 MIN/MAX ±1024，拖动事务按 1024 间隔重排。长按就绪时轻微内缩、低阴影与触觉反馈，松开复原，不向边界外放大。
DDL 由年月日时分数字滚轮选择，无值默认当前时间，有值回显原值；年月变更修正月份天数。时间为 epoch 毫秒，以设备时区显示。

|状态|条件|显示及排序|
|---|---|---|
|普通|无 DDL 或尚未进入提醒期|手动排序；绿色逐项变浅|
|即将截止|now >= deadline - reminderMinutes，且 now < deadline|浅红卡片，时钟图标|
|已逾期|now >= deadline|浅红卡片、警告图标、灰标题和较深边框|

提醒时限每队列独立，默认 60 分钟，可设 0–5256000 分钟。所有提醒任务合并按 DDL 升序置顶，不区分两个排序分组。非提醒事项继续原手动顺序，渐变从首个非提醒任务重新开始，第七个起保持终点色。提醒事项不能通过拖动覆盖自动顺序。
前台每秒检查；暂停时停止，回前台重查；没有后台通知、系统闹钟或推送，不保证关闭应用时发声/弹通知。

## 完成、撤销与回收站
完成写入 state=1 和 completed，卡片淡出，显示短暂撤销入口；撤销恢复待办并清空 completed，保留位置。完成时尝试播放可选 completion 音效；系统触摸音不由应用主动播放。
回收站每队列独立，显示完成时间；左侧恢复需选队头/队尾，右侧垃圾桶直接清除且不二次确认。恢复后满足 DDL 条件仍自动置顶。清空回收站需确认“清除全部已完成事项？”，仅当前队列生效。待办三点菜单的删除需确认并物理删除，绕过回收站。

## 视觉与全局数据
浅色为柔和米绿，深色跟随系统，以深森林绿保持对比。大字体或小屏将右侧操作移到下一行。添加事项文字单独居中；侧栏创建按钮加号文字组合居中，全局设置为较小底部入口。
备份包含全部队列、待办、回收站、备注、DDL、完成时间、排序及设置，包括已删除队列的本地墓碑记录。导入为副本，不覆盖现有队列；全局设置采用备份值，重复导入会重复创建。详见 DATA.md。
